### Claude — 2026-07-31T04:00:23.517Z

Found the official answer. To add alt text for images in your Google Doc content source (for AEM Edge Delivery Services):

1. Right-click the image in the Google Doc.
2. Select **Alt Text** from the context menu (or go to **Format → Alt text**).
3. Enter a **Description** — this is what gets carried through as the `alt` attribute on the generated `<img>` when the page is previewed/published.
4. Preview the page afterward so the change picks up.

A couple of things worth knowing per AEM's guidance ([docs/media](https://www.aem.live/docs/media)):
- Only add alt text for images that are **informative or functional**. For purely **decorative** images, leave it empty (`alt=""`) so screen readers skip them — don't just fill in something generic.
- Alt text is contextual: the same image reused elsewhere on the site may deserve different alt text depending on surrounding content, since it's tied to the reference, not the asset itself.

If you have many images across many docs and want to batch-check/update them, I can help write a script (e.g. using the Google Docs API) to audit which images are missing alt text — let me know if that's what you're after.
